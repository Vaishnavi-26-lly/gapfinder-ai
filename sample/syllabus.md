# Operating Systems — Syllabus

Unit 1: Processes and Threads
Process states, PCB, context switching, threads vs processes.

Unit 2: CPU Scheduling
FCFS, SJF, Round Robin, priority scheduling, turnaround and waiting time.

Unit 3: Synchronization and Deadlocks
Critical section, semaphores, mutex, deadlock conditions, prevention, avoidance (Banker's algorithm).

Unit 4: Memory Management
Paging, segmentation, virtual memory, page replacement (FIFO, LRU), thrashing.
